# HAVI-dashboard

Healthcare Access Vulnerability Index Dashboard

Interactive dashboard for the Healthcare Access Vulnerability Index (HAVI), a county-level index of healthcare access vulnerability across all 3,144 U.S. counties.

Live app: https://havi-dashboard.streamlit.app

The scheduled workflow in .github/workflows keeps the free Streamlit deployment awake, which creates the automated "Keep Streamlit app awake" commits.

Congressional App Challenge Award 2026 Winner (Wisconsin 3rd Congressional District)

Developed by Ali Abidi.

```bash
pip install -r requirements.txt
streamlit run app.py
